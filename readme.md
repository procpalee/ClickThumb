# 🎨 ClickThumb (나만의 썸네일 생성기) 사용 설명서

설치 없이 브라우저에서 바로 실행 가능한 **'ClickThumb'** 사용법을 소개합니다.
복잡한 디자인 툴 없이도, 몇 번의 클릭만으로 블로그와 유튜브에 최적화된 고퀄리티 썸네일을 만들 수 있습니다.

## 제작 동기

워드프레스 블로그와 네이버 블로그 운영을 시작하면서 썸네일의 중요성을 알게 되었습니다. 다만 이를 매번 만드는 것은 번거로운 일이었습니다.

미리캔버스와 피그마 같은 툴을 사용하더라도 의외로 많은 시간이 소요 되었고 "내용이 중요한데, 껍데기 만드는 데 힘을 빼고 있구나"라는 생각이 들었습니다.

나노바나나와 같은 생성형 AI에게 만들어 달라고 할 수도 있지만 매번 썸네일을 요청할 때마다 토큰이 소모된다는 점이 부담스럽고, 시리즈나 카테고리별로 일관된 톤앤 매너를 유지해야 하는데 생성형 AI의 특성상 한계가 있었습니다.

또한 썸네일을 자동으로 만들어 준다는 서비스가 존재하긴 했지만 디자인적으로 너무 획일화 되어 있고 제가 원하는 기능을 갖추고 있지 않아 **직접 제작**하게 되었습니다.

## 주요 특징

- **설치 없는 간편함**: HTML 파일 하나만 열면 바로 실행됩니다.
- **네이버 블로그 최적화 템플릿**: 기본 화면은 **태그·제목·부제 3개 입력**과 버튼 2개가 전부입니다. 비율은 네이버 블로그에 최적화된 **배경 16:9 (1280×720) + 콘텐츠(Safe Zone) 1:1** '만능 비율'로 고정되어 있어, 가로형 헤더로도 쓰고 가운데만 잘라 정사각으로 공유해도 텍스트가 잘리지 않습니다.
- **배경 자동 생성**: **[🎲 배경 자동 생성]** 버튼 한 번으로 무료 사진(Lorem Picsum)이 배경에 자동 적용됩니다. 사진 밝기를 분석해 글자가 잘 보이도록 **어둡기(Overlay)** 까지 자동 조절되며, 오프라인이면 어울리는 그라디언트 배경으로 대체됩니다.
- **최신 디자인 트렌드 반영**: 깔끔한 **Pretendard 폰트**와 세련된 **글래스모피즘(Glassmorphism)** 스타일이 기본 적용되어 있습니다.
- **고급 설정 (필요할 때만)**: "⚙ 고급 설정"을 펼치면 기존의 세부 기능을 모두 쓸 수 있습니다.
    - **폰트 & 타이포**: 폰트 3종(Pretendard, Noto Sans, 고운바탕)과 굵기/크기 조절
    - **색상 & 배경**: 텍스트/그라디언트 색상, 이미지 직접 업로드, 어둡기(Overlay) 조절
    - **비율 & 내보내기**: 배경/콘텐츠 비율, 픽셀 크기, 화질(1x~4x), 포맷(WebP/PNG/JPG) 변경
- **쾌적한 사용성**:
    - **실시간 미리보기**: 입력하는 즉시 디자인이 화면에 반영됩니다.
    - **철저한 보안**: 입력한 내용이 서버로 전송되지 않고 내 컴퓨터(브라우저)에서만 작동합니다.

## 사용 방법 (Step-by-Step)

### 1. 프로그램 실행
다운로드 받은 `index.html` 파일을 더블 클릭합니다. (웹 서버에서 접속 시 URL 클릭)

### 2. 내용 입력 (Content Controls)
왼쪽의 텍스트 입력란에 내용을 적어주세요.
- **태그 (Tag)**: 블로그 카테고리나 시리즈 명 (예: REVIEW, TIP)
- **제목**: 핵심 메시지 (입력하는 대로 실시간 반응하며, Safe Zone을 넘어가면 자동 줄바꿈 됩니다)
- **부제**: 보충 설명

### 3. 배경 자동 생성 (Auto Background)
**[🎲 배경 자동 생성]** 버튼을 누르면 배경 사진이 자동으로 들어가고 어둡기도 자동 조절됩니다. 마음에 드는 사진이 나올 때까지 다시 눌러보세요. 직접 고른 사진을 쓰고 싶다면 고급 설정의 **[이미지 업로드]**를 이용하세요.

### 4. 저장하기 (Export)
**[이미지 다운로드]** 버튼을 클릭하면 네이버 블로그에 최적화된 **1280×720 WebP** 썸네일이 저장됩니다.

### 5. (선택) 고급 설정 (Advanced)
폰트·색상·비율·포맷 등을 바꾸고 싶을 때만 **"⚙ 고급 설정"**을 펼쳐 조정하세요. 그라디언트 색상 변경, 배경 초기화, 배경 어둡기 수동 조절, 4배(4x) 고화질 내보내기 등이 모두 여기에 있습니다.

## 💡 활용 팁
- **만능 비율 (16:9 + 1:1)**: 기본값이 배경 **16:9** + 콘텐츠 **1:1**인 이유입니다. 이렇게 만든 썸네일은 네이버 블로그/유튜브 헤더(가로형)로도 쓰고, 가운데만 잘라서 인스타그램/카카오톡(정사각)으로 공유해도 텍스트가 잘리지 않는 **'만능 썸네일'**이 됩니다.
- **시리즈별 컬러링**: 시리즈나 주제별로 고유한 **태그 색상**과 **그라디언트 조합**을 정해두면, 독자들이 썸네일 색깔만 보고도 주제를 파악할 수 있습니다.
